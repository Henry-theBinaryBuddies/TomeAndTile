# Dev logs

One file per person. At the end of every working session, that person's Claude appends an entry to the **top** of their file. Entries are never edited afterwards.

## Entry format

```markdown
## 2026-11-14 — #12 Chat panel

**Did:** what changed, in two or three lines. Link the PR.
**Directed Claude to:** the approach asked for, and anything Claude got wrong that had to be corrected.
**Learned:** something not obvious before the session.
**Blocked on / next:** what is waiting on someone else, and what comes next.
```

Keep it honest and short. "Nothing merged; spent the session finding out why X fails" is a good entry.
